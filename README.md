# MediNova – Healthcare Management Web Application

MediNova is a **responsive frontend healthcare management web application** designed to provide users with a seamless interface for exploring medical departments, healthcare services, doctors, and appointment-related information.

The application features a modern and user-friendly healthcare interface with dedicated pages for doctors, individual doctor profiles, departments, services, appointments, and contact information.

## 🚀 Project Overview

MediNova is developed as a **multi-page frontend web application** using HTML5, Tailwind CSS, and JavaScript.

The project focuses on building a professional healthcare platform with responsive layouts, structured navigation, reusable UI patterns, doctor profile pages, service sections, and an appointment interface.

The application is currently focused on the **frontend experience**, with scope for future backend integration, database connectivity, authentication, and real-time appointment management.

## ✨ Key Features

* **Responsive Healthcare Interface**

## 📱 Responsive Design

MediNova follows a responsive-first approach to provide a consistent experience across different devices.

The interface is designed to adapt to:

* Mobile devices
* Tablets
* Laptops
* Desktop screens

Tailwind CSS responsive utility classes are used throughout the application to create flexible layouts and responsive components.

## ⚙️ Frontend Architecture

MediNova follows a **multi-page frontend architecture**, where each major healthcare functionality is represented by a dedicated HTML page.

JavaScript functionality is implemented on the client side, while Tailwind CSS is used for responsive styling and UI development.

The project currently does not include a backend or database layer.

## 🚀 Getting Started

### Prerequisites

No special software or backend environment is required to run the application.

A modern web browser is sufficient.

### Run Locally

1. Clone the repository:

```bash
git clone https://github.com/your-username/MediNova.git
```

2. Navigate to the project directory:

```bash
cd MediNova
```

3. Open `index.html` in a web browser.

For development, the project can also be opened using **VS Code with the Live Server extension**.
